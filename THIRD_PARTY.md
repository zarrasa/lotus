# Third-party components

Lotus bundles the following components unchanged. Each keeps its own license;
license texts are shipped next to the files.

| Component | Version | Where | License |
|---|---|---|---|
| [zapret](https://github.com/bol-van/zapret) (winws) by bol-van | v72.13 | `bin/` | MIT — `bin/LICENSE.txt` |
| [WinDivert](https://reqrypt.org/windivert.html) by basil00 | 2.2 | `bin/`, `bin/gdpi/` | LGPL-3.0 / GPL-2.0 — `bin/gdpi/LICENSE-windivert.txt` |
| [GoodbyeDPI](https://github.com/ValdikSS/GoodbyeDPI) by ValdikSS | 0.2.3rc3 | `bin/gdpi/` | Apache-2.0 — `bin/gdpi/LICENSE-goodbyedpi.txt` |
| [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) by Flowseal | v1.11.4 | `tgproxy/` | MIT — `tgproxy/LICENSE` |
| [Font Awesome Free](https://fontawesome.com) | 6.5.2 | `icons/`, `tools/fonts/` | Icons CC BY 4.0, fonts SIL OFL 1.1 — `icons/LICENSE-fontawesome.txt` |

Python libraries used at build time (customtkinter, Pillow, pystray, cryptography,
httpx, h2, certifi, PyInstaller) are installed from PyPI under their own licenses.
